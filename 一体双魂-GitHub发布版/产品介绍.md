# 一体双魂

**两个灵魂，一起思考，也一起记得。**

一体双魂是一款以「一个身体，两个灵魂」为角色设定的双 AI 聊天与协作工作台。两位角色拥有各自的性格、声音和看待问题的角度，同时共享同一段会话的经历。你可以和她们聊日常、谈心事，也可以一起推敲创意、整理计划、处理工作。

**两个灵魂，可以来自同一个模型。** 既可以让 GPT 与 DeepSeek 等不同模型协作，也可以让同一个模型分别扮演两位独立的 Agent。名字、人设、头像与模型分开设置，一键就能让两位使用相同模型。开启讨论后，她们分别读取各自的角色卡，先独立给出意见，再由最终发言者结合双方观点审阅、整合。相同模型仍可能产生相似错误，双方同意不代表结论必然正确。

**由谁开口，你来决定。** 开启双魂讨论后，两位角色会先交换简短意见，再由你选择的角色回应，或分别表达各自的看法。直接喊出「DeepSeek」或「GPT」的名字，也能把话交给对应的人格。电脑端还可以查看角色讨论摘要，了解她们提出了哪些不同的意见。

**值得记住的事，放进宝箱。** 一句约定、一次重要的决定、一段特别的交流，都可以手动珍藏；开启自主珍藏后，双魂也会共同判断哪些对话值得留下。宝藏保存日期、摘要和对话原文，在以后的相关话题中帮助找回过去的细节。你可以随时查看、搜索，并决定哪些宝藏继续参与回忆。

**从电脑聊到 QQ，让交流自然延续。** 通过 SnowLuma 接入 QQ 后，可以在电脑与 QQ 私聊之间继续同一段会话，也可以在允许的群聊中通过 @ 唤起她们。私聊与各个群分别保存上下文和宝箱；群聊只提供基础文字交流，不调用编程、生图等工具。

你还可以分别编写两位角色的人设，选择模型，更换背景、工作台图标和角色头像。程序附带默认图片，也支持上传自己的图片，让这个共同的空间慢慢长成你喜欢的样子。

**支持 ChatGPT 订阅账号接入。** GPT 一侧可通过已登录 ChatGPT 账号的本地 Codex 使用相应订阅权益，也提供符合条件时的官方 ChatGPT 授权接入方式。完成所需安装、登录及授权后，这条接入路径无需另填 OpenAI API 密钥。Plus 等订阅账号能否使用某种接入方式、可选哪些模型，以实际账号权限和授权结果为准。[OpenAI 官方登录说明](https://learn.chatgpt.com/docs/auth)、[订阅授权说明](https://developers.openai.com/siwc/token-sharing-open-source)。

**选择订阅接入前，也请了解这些不足：**

- **有额度限制。** 请求会消耗对应订阅额度，并非无限使用；长上下文、多轮讨论会增加消耗，具体上限与恢复时间以账号用量页面为准。[官方用量说明](https://learn.chatgpt.com/docs/pricing)。
- **回复可能需要更久。** 本地 Codex 接入需要安装、登录，并可能产生启动开销；双魂先讨论再回答也会增加模型调用和等待时间。
- **当前 GPT 接入以文字交流为主。** 本工作台的 GPT 调用用于聊天、分析和整合，不会完整复现 ChatGPT 客户端的语音、生图、插件和工具能力，也不会自动导入你原有的 ChatGPT 聊天记录。
- **需要维护连接。** 登录过期、网络异常、模型或官方接口调整，可能需要重新授权、更新程序或重新选择模型。官方订阅授权接口目前也有功能限制。[官方接口限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。
- **DeepSeek 需要单独配置。** ChatGPT 订阅不提供 DeepSeek 的账号或模型额度；DeepSeek 与 QQ 连接仍需自行准备。

设置、聊天记录和宝箱保存在本机；使用模型时，相关对话会发送给你配置的模型服务。
