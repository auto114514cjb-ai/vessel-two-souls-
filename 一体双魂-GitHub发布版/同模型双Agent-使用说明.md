# 一体双魂 1.5.0 · 同模型双 Agent

现在可以让同一个模型分别承担两位 Agent，也可以继续使用不同模型。两位共用聊天记录和宝箱，分别使用自己的名字、角色卡及头像。它们是由独立请求实现的角色 Agent，并不是两个独立训练的新模型。

## 开启方法

1. 打开工作台「连接与设置」，找到 **04 / 双 Agent · 角色与模型**。
2. 将运行方式改为 **自定义双 Agent（可使用同一个模型）**。切换时会勾选「双魂先交流，再由所选人格回答」。
3. 为 Agent A 选择接入来源，点击「读取 Agent 模型列表」，再从下拉列表选择模型。
4. 点击 **让 B 与 A 使用相同模型**。按钮只复制接入来源与模型，保留双方名字、角色卡和头像。
5. 分别设置两位的名字，在 **06 / 预载角色卡** 编辑各自人设，然后「保存并连接」。

例如，两位都用同一个 GPT 模型：A 的角色卡偏共情、创意，B 的角色卡偏分析、审阅。也可以两位都选择同一个 DeepSeek 模型。模型列表来自你的实际连接，程序不会虚构可用模型。

支持的文字接入来源：Harness 中配置的模型、DeepSeek API、已登录的本地 Codex、符合条件并完成授权的 ChatGPT 订阅。新连接或密钥请先在「原有连接」模式保存，再回来读取模型列表。订阅权限与额度以实际账号结果为准。

## 聊天方式

- 选择底部角色按钮，决定谁最终发言；或者直接说「小理，你怎么看？」。
- `/a 问题` 指定 Agent A，`/b 问题` 指定 Agent B。原 `/deepseek`、`/gpt` 仍分别对应 A、B。
- 开启讨论后，两位先各自生成简短的角色意见，首轮不把一位的意见送给另一位；随后把双方意见交给最终发言者审阅、修正和整合。
- 勾选「在本地显示双魂讨论」，可看角色发言摘要与本轮所用模型。它不是隐藏思考过程，QQ 只收到最终答复。
- 自主珍藏继续要求双方共同同意、记录完整且最终回答成功。模型相同也不会把一张赞成票算成两张。

## 群聊与工具

默认继续使用原有 QQ 群聊模型配置。需要群聊也使用新选的模型时，勾选 **群聊也使用这组 Agent 模型**。

这时两位必须使用 Harness、DeepSeek API 或 ChatGPT 授权文字接口。**本地 Codex 仅支持电脑和私聊**；群聊始终不进入 Codex 或 Harness 工作代理。群聊继续只响应已允许群中的 @，并与私聊、其他群隔离记录和宝箱。

自定义双 Agent 模式用于文字讨论、分析和整合，不调用工具。需要沿用原 Harness 的工作工具时，可切回「原有连接」。已有连接设置、聊天记录及宝箱会保留。

## 使用成本与局限

同一个模型也需要分别调用。开启讨论通常比单角色直接回答多两次调用，会增加等待时间和额度消耗；共同错误也可能出现在双方意见中，重要结论仍需核对。
