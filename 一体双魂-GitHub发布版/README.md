# 一体双魂

**一个身体，两种声音，一份共同的记忆。**

一体双魂是一款运行在电脑本地的双 AI 聊天与协作工作台，支持不同模型协作，也支持同一模型的两位独立 Agent。你可以为 DeepSeek 和 GPT 分别编写角色卡，让两位人格先交换简短意见，再由指定的一位或两位共同回应。电脑聊天与 SnowLuma 接入的 QQ 会话共用记录；重要的约定和经历可以放进「宝箱」，在以后相关的聊天中重新拾起。

## 主要功能

- **同模型双 Agent**：名字、人设与模型分开设置。可一键让两位使用同一模型，先分别形成意见，再由最终发言者审阅整合。也支持各自选择不同来源、不同模型。

- **一体双魂角色卡**：共同人设与两份独立角色卡，支持导入、导出、恢复默认。
- **先讨论，再回答**：可选双人格讨论；本地可查看生成的角色发言摘要。摘要不是模型的隐藏思考过程，也不会发送到 QQ。
- **指名回应**：例如「DeepSeek，你今天觉得怎么样」由对应角色最终回答；也可选择分别回答、协作整合、GPT 或 DeepSeek。
- **共同记忆与宝箱**：手动珍藏，或开启双魂讨论与自动珍藏，由两位都同意后保存。宝藏含日期、摘要、原文；支持查看、搜索、移出自动回忆和恢复。回忆有数量与长度限制，并非保证逐字记住所有历史。
- **电脑与 QQ**：SnowLuma 的 OneBot v11 正向 WebSocket 为可选入口；私聊与每个群的上下文及宝箱分别保存。
- **群聊 @ 回复**：允许的群内成员 @机器人即可聊天；群聊走纯文字接口，不进入 Harness 或 Codex 工具代理。
- **模型下拉选择**：从已配置的连接读取可用模型，无需手动记住模型名。
- **自定义外观**：工作台名称、背景、图标、两位角色头像和背景强度。附带原创默认背景、图标及头像，可随时恢复默认。
- **快捷指令**：私聊输入 `/help` 查看帮助，`/status` 查看双魂与珍藏状态，`/treasure 名称` 手动珍藏，`/new` 开始新会话。`/gpt`、`/deepseek`、`/both`、`/team` 可切换本次回答方式。

## 运行要求

- 推荐 Windows 10/11，安装 [Node.js](https://nodejs.org/) 22 或更新版本。
- 程序无需安装 npm 依赖。
- 模型、DeepSeek Harness、Codex 和 SnowLuma 均需自行安装或配置。此发布包不附带第三方软件、账号、密钥或付费额度。

## 第一次启动

1. 解压到普通可写目录，安装 Node.js 后重新打开启动窗口。
2. Windows 双击 **一键启动.cmd**。也可在程序目录运行 `node server.mjs --open`，或 `npm start`。
3. 浏览器打开 `http://127.0.0.1:17860/`，点击「连接与设置」。首次运行自动创建本机配置。
4. 配置 DeepSeek 和 GPT。QQ、双魂讨论、自动珍藏都可以稍后开启。
5. 点击「外观与图标」选择本地图片，每张不超过 5 MB，支持 PNG、JPG、WebP、GIF。

关闭启动窗口会停止本次启动的服务。端口被占用时请使用已打开的工作台；需要另设端口时可设置 `AI_DESK_PORT`。订阅登录的本机回调地址应保持与已注册配置一致。

### DeepSeek

**沿用 Harness**：先安装并完成 DeepSeek Harness 初始配置；在本工作台目录运行「安装Harness桥接.cmd」，然后在空闲时完全退出并重新打开 Harness。安装器只更新标记为本工作台桥接的一段配置，并在本工作台 `data/` 保存首次备份。移除桥接使用「移除Harness桥接.cmd」。搬动工作台后需要重新安装桥接并重启 Harness。

Harness 的工作会话沿用原助手与工具。工具确认在 Harness 原窗口处理。工作台的双魂内部讨论和群聊使用纯文字接口。

**独立 API**：切换到 DeepSeek API，在本机设置地址、密钥和模型。此方式只提供文字聊天。

### GPT

- **Codex**：安装并登录自己的 Codex。程序会寻找 Windows 桌面版管理的 Codex 可执行文件或 PATH 中的 `codex`，也可以在设置中指定路径。可用「登录Codex.cmd」完成官方登录。当前 GPT 调用用于文字分析与整合，使用只读模式，不自动控制 ChatGPT 桌面窗口。
- **ChatGPT 订阅接入**：代码提供官方授权流程，需要账号和应用获得相应权限后才能使用。Plus 身份不等于已经配置成功，也不等于包含 API 余额；以实际授权结果和官方账户权限为准。Windows 登录信息使用当前用户的系统保护。此发布包不包含任何登录信息。
- **群聊 GPT**：在设置中选择 Harness 中的文字模型，或实际可用的 ChatGPT 授权接入。群聊不会转入 Codex 工具代理。


### GPT 订阅接入的限制

GPT 可通过已登录 ChatGPT 的本地 Codex 使用相应订阅权益，也可在满足条件并完成官方授权后使用 ChatGPT 订阅接入。此路径无需另填 OpenAI API 密钥，但不能仅凭 Plus 身份判断已经接入成功；实际可用模型及权限以账号结果为准。[官方登录说明](https://learn.chatgpt.com/docs/auth)、[订阅授权说明](https://developers.openai.com/siwc/token-sharing-open-source)。

- 订阅有用量限制，并非无限请求。长上下文与双魂讨论会增加消耗；以账号用量页面的限额和恢复时间为准。[官方用量说明](https://learn.chatgpt.com/docs/pricing)。
- 本地 Codex 需要安装和登录，每次调用可能有启动开销；双魂讨论也会增加等待时间。
- 本项目的 GPT 接入目前用于文字聊天、分析与整合，不完整复现 ChatGPT 的语音、生图、插件及工具功能，也不自动导入原有 ChatGPT 会话。
- 登录过期、网络或官方接口变动可能需要重新授权或更新。官方订阅授权接口仍有功能限制。[官方接口限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。
- DeepSeek 仍需单独配置账号与额度。ChatGPT 订阅不提供 DeepSeek 服务。

### QQ / SnowLuma

1. 自行安装并登录 SnowLuma，启用 OneBot v11 正向 WebSocket，填写它实际显示的地址与 accessToken。
2. 在工作台填写自己的 QQ 号并开启 QQ 私聊。私聊只响应配置的主人账号。
3. 群聊需另外开启并填写允许的群号；允许群内任何成员 @机器人即可触发。
4. 关闭 SnowLuma 中原有 AI 自动回复，避免它与本工作台同时回复。

默认启动器可识别程序目录下已有的 `SnowLuma/`，或环境变量 `SNOWLUMA_HOME` 指向的目录，并在启用 QQ 时尝试启动。也可以自行打开 SnowLuma。

## 使用同模型双 Agent

在「连接与设置 → 04 / 双 Agent · 角色与模型」选择「自定义双 Agent」，为 A 从下拉列表选择接入来源与模型，再点击「让 B 与 A 使用相同模型」。这只复制模型选择，不改动双方名字、角色卡和头像。保持「双魂先交流」开启即可先讨论后回答。详见 [使用说明](同模型双Agent-使用说明.md)。

支持 Harness 文字模型、DeepSeek API、本地 Codex 与符合条件的 ChatGPT 订阅授权；可用模型来自实际连接。配置新密钥时先在「原有连接」模式保存，再回来读取列表。自定义模式是独立文字请求，不调用原 Harness 工作代理；原有工具工作方式可以切回「原有连接」。

同模型也会分别调用、分别判断是否珍藏，不会重复使用同一份答复作为双方意见。内部摘要和宝箱按角色名字保存。两个 Agent 仍可能犯相同错误，不是两套独立训练的模型。

群聊默认保留原有纯文字配置。勾选「群聊也使用这组 Agent 模型」后可以共享新模型选择，但不允许本地 Codex；群聊始终只聊天、不调用工具。

快捷指令新增 `/a` 与 `/b`，分别指定两位角色；也可直接用自定义名字点名。


## 本机数据与发布

连接设置、登录凭据、聊天、外观配置及上传图片存于 `data/`；宝藏存于「宝箱」。这些都是私人数据，不应上传 GitHub。聊天使用所选模型时，会向对应服务发送需要的上下文及相关宝藏。

发布包只包含源码、测试、默认角色卡和默认图片。**不要把正在使用的整个目录直接上传**；请使用经过检查的干净发布包。`.gitignore` 只是辅助，不能清除已提交的历史秘密。
