# vessel-two-souls-
一体双魂是一款连接电脑与 QQ 的双 AI 聊天与协作工作台，以“一个身体、两个灵魂”为角色设定。 - 特色：支持不同模型协作，也支持同一模型的两个独立 Agent；可自定义名字、角色卡、头像和背景；先独立提出意见，再审阅整合；“宝箱”支持手动珍藏、双方共同判断后自主珍藏及相关回忆。 - 作用：用于日常聊天、创意讨论、任务规划和方案审阅；支持 QQ 私聊与群聊 @ 回复；可通过本地 Codex 或符合条件的 ChatGPT 授权使用订阅权益接入GPT可以直接登录本地客户端，不需要使用APIKEY接入QQ。 - 缺点：双 Agent 会增加等待时间和额度消耗，同模型可能共同犯错；账号与 QQ 需自行配置；自定义双 Agent 和群聊仅提供文字交流，V1.6.0版本后支持识图，订阅接入受账号权限及额度限制。
